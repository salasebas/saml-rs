# Domain docs

Read `GLOSSARY.md` at the repo root for the domain terms before you name a
type, an option, or an error. Use its terms in code, docs, and issues.

API design and naming rules are in `CODING_STANDARDS.md`. The SAML rules each
flow claims are in `docs/conformance/`, and how to read the specifications is
in `docs/standards-conformance.md`.
